# Enttec DMX USB Pro (70304)

The USB DMX interface the app was built for. Its serial protocol, the DMX USB Pro API (v1.44), is what
`src/main/dmx/enttecProPacket.ts` and `scripts/dmxRangeTest.ps1` follow.

- Product page: https://www.enttec.com/sku/70304
- DMX USB Pro API: https://support.enttec.com/dmx/usbdmx-dmx-usb-pro-70304/dmx-usb-pro-api
